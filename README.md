## 表里看不到、但决定你用不用得爽的几个细节

**英国有三档，差在 IP 属性和回程。** AUD$10.90 那款产品页写明是「非家宽 IP」，只是英国原生 IPv4；AUD$14.90 才是英国原生家宽；AUD$19.90 在原生家宽基础上加了「三网回程优化，直连即可直播」。做短视频起号，前两档的差别比价格差更值得在意，家宽 IP 在注册阶段的通过率通常更好。做直播，19.90 那档省下的是中转的钱和调试时间。

**日本两款差 30 澳元。** AUD$19.90 的页面直接写「无优化，需要中转」；AUD$49.90 是双 ISP 加三网回程优化，官方标注直播无需中转。带宽上反而是便宜那款更高（200Mbps 对 50Mbps），流量也更多。差价买的是回程线路，不是配置。

**澳大利亚两款同价，线路策略不同。** 墨尔本款写「三网回程优化，直播无需中转」；悉尼款写「联通移动直连，电信去程绕路回程直连」。早两年的第三方测评常说「电信别选澳洲、会绕美国」，这个结论对悉尼款还有部分适用，对墨尔本款已经不成立了，下单前看清楚是哪一款。

**西班牙是唯一写明「必须加中转才能正常」的地区。** 法国是同价位的「建议加中转」。这两个国家的套餐便宜，但中转的钱要算进总成本。

**美国四款里，12.90 的两款走 4837，15.90 和 16.90 的两款走 9929。** 四款都写着「无需中转」。做直播优先 9929 那两款，只是发视频、起号，12.90 的静态家宽够用。

**流量是双向算的。** 标 2TB 是上传加下载合计。直播推流会持续消耗上行，一个 200Mbps 的直播款如果长时间高码率推流，2TB 比想象中掉得快。

**部分套餐超流量限速 5Mbps 而不是停机。** 英国TikTok专用、菲律宾、马来西亚几款的产品页写了这条。限速不停机意味着直播会直接卡死但机器还在，做直播的话要么提前盯流量，要么别选标了限速的款。

**新加坡两款状态不一样。** AUD$16.90 的「新加坡Tiktok专用」是原生 IDC IP，当前页面显示无库存；AUD$24.90 的「新加坡TK直播线路」有货，原生 IPv4，移动可直连、直播建议中转。

## 几个下单前常问的问题

**IP 是住宅还是机房？**
按节点分，不是全站住宅。澳大利亚用静态家宽 IP，美国分 Cogent 家宽和 GTT/NTT 双 ISP 家宽，韩国、新西兰、菲律宾、西班牙、法国、泰国、印尼、马来是原生家宽，英国有一款明确标「非家宽」，新加坡分原生 IDC 和直播线路两种。下单前一定看具体产品页的 IP 说明。

**要不要另外买中转？**
看产品页写什么。写了「无需中转」「直连即可直播」的不用买；写「建议中转」的可以先不买，跑起来看延迟；写「必须加中转才能正常」的（西班牙）绕不开。WePC 自己有中转产品，AUD$29.90 一个月，500GB 流量、3 个中转，深港 IEPL 和海外优化双线路。这个价格不便宜，只做一两个号的话，先试直连。

**流量用完了会怎样？**
双向计算，超了之后部分套餐限速到 5Mbps 不停机、不额外收费。但直播场景下限速等于中断，提前在后台看流量使用情况。

**能不能只买一个月试试？**
可以，月付配 `WePCMON90`。注意 3 天退款窗口和月付周期不是一回事，测试要在前 3 天做完。
